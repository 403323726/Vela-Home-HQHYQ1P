# Changelog

## 2.8.7 - 2026-10-25

- Added Simplified Chinese / English language switching.
- Persisted the selected language across process restarts.
- Fixed the settings Activity losing its result after `recreate()`, which left Home in the old language.
- Added a square 512×512 and 1024×1024 export of the launcher icon.
- Packaged the tested HaQu Q1 Pro APK, ADB tools, screenshots, and bilingual adaptation guides.

## Earlier device-specific work

The 2.8.x line includes the Apple TV-style Vela Home layout, app hiding, app information, reordering, a three-column system-app folder, default-Home handling, Dangbei OS background restrictions, HDMI/input routing, and the HaQu Q1 Pro device configuration.

The upstream CleanYourTV project contains the original launcher and broader device support. This repository is a focused, device-specific derivative.
